## 4. Recommended thumbnail concept

NOD faces one large, visibly unfinished project at the boundary between `NOW` and `LATER`. Present-NOD pushes the project toward future-NOD, who must carry the accumulated burden. The only large thumbnail text is `NOT NOW.`

Requirements:

- one dominant character action;
- one dominant unfinished object;
- high contrast and mobile readability;
- no phone, notification or dopamine imagery;
- no small explanatory labels required for comprehension;
- the image must show postponement rather than generic sadness or fatigue.

The thumbnail and title must complement rather than repeat each other. The title supplies importance; the image supplies the immediate postponement decision.

## 5. Cold-open variants

### Cold open A — recommended: relief now

There’s a task you genuinely care about.
So naturally, you do everything except it.

You clear one email. Rename a file. Watch one useful video about how to begin.
And each detour makes sense, because it gives you something the real task does not: relief.

Procrastination is not always choosing fun over work. Often, it is choosing a better feeling now over a better outcome later.

So if waiting for motivation keeps failing, we need to change the first moment instead.

Why it leads: it begins with recognizable behavior, creates a paradox, reveals the relief mechanism quickly and opens a practical loop without pretending to explain every form of procrastination.

### Cold open B — future-self transfer

Every time you postpone this task, it does not disappear.
It changes owners.

For a few minutes, present-you gets relief. Tomorrow-you gets the same task, less time and slightly more pressure.

That trade can feel rational in the moment, even when you care deeply about the result.

So the problem may not be that you do not want the outcome. The problem may be what the first moment of starting makes you feel.

Strength: directly matches the proposed thumbnail and provides a distinctive visual metaphor.

Risk: it reaches the concrete avoidance scene slightly later than cold open A.

### Cold open C — false preparation

You open the project, feel the first hint of resistance and decide to prepare a little more.

You organize the folder. Find the right tool. Make a better plan.

It looks like progress. But none of it requires you to face the part you are avoiding.

The question is not only why you procrastinate. It is what your procrastination helps you escape for the next five minutes.

Strength: sharp distinction between preparation and first meaningful action.

Risk: narrower identification because not every viewer procrastinates through preparation.

## 6. Recommended opening model

```text
TASK CUE
   ↓
DISCOMFORT / UNCERTAINTY
   ↓
SMALL ESCAPE
   ↓
RELIEF NOW
   ↓
TASK RETURNS LATER
```

The model must be presented as one common loop, not a universal diagnosis.

## 7. Practical deliverable

The video should lead to one bounded experiment:

1. Catch the first escape after the task cue.
2. Name the immediate state being avoided without diagnosing it.
3. Replace the abstract task with one visible physical action.
4. Attach that action to a specific cue using an if-then plan.
5. Run the experiment once without promising permanent change.

Example: `If I open the project and reach for a substitute task, then I will write one deliberately rough sentence before deciding what to do next.`

The final script must not imply that one rough sentence, five minutes of work or an if-then plan cures procrastination.

## 8. Retention architecture

Proposed runtime: approximately 6:30–7:30.

1. Recognizable avoidance scene.
2. Relief-now reveal.
3. Present-self versus future-self transfer.
4. Task aversiveness, ambiguity and evaluation cost as possible branches.
5. The first-escape diagnostic.
6. One visible next action.
7. If-then cue.
8. Bounded viewer experiment.
9. Return to the opening project.

The first mechanism reveal should occur within approximately 25 seconds. No greeting, channel introduction, dictionary definition or long scientific preamble should precede it.

## 9. Claims boundary

Allowed:

- procrastination can function as short-term mood repair;
- task aversiveness, uncertainty, anticipated effort and fear of evaluation can contribute;
- different viewers may delay for different reasons;
- making the first action concrete may reduce ambiguity;
- implementation intentions can support goal initiation;
- the protocol is a bounded experiment.

Prohibited:

- all procrastination has one cause;
- the viewer’s brain is universally protecting them;
- diagnosing ADHD, anxiety, depression or executive dysfunction;
- claiming motivation never matters;
- unsupported dopamine, reset or brain-hack framing;
- promising permanent elimination of procrastination.
