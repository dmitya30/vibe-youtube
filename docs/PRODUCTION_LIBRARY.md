# Production and discovery library

Updated: 2026-08-22
Status: DEFINITION CREATED / IMPLEMENTATION PENDING

## 1. Purpose

The library converts experience from VIDEO-001–004 into reusable assets. It must reduce the cost and time of future probes without forcing different channels into one visual or narrative template.

## 2. Library layers

### Production components

- Remotion layout, typography and motion primitives;
- caption, timing and narration utilities;
- media validation and contact-sheet tools;
- publication packet, checksum and backup tools;
- channel-specific style tokens separated from generic components.

### Hook and retention patterns

For every pattern record:

- viewer tension;
- opening mechanism;
- information withheld and revealed;
- visual interruption;
- expected payoff;
- observed retention evidence;
- failure cases.

### Packaging patterns

Record:

- title structure;
- thumbnail structure;
- mobile readability;
- curiosity mechanism;
- promise-content match;
- impressions, CTR and traffic source;
- sample-size warning.

### Evidence and case studies

Record:

- primary URL;
- capture date;
- public metrics;
- channel baseline comparison;
- recurrence across independent creators;
- possible paid traffic or marketing conflict;
- confidence and falsification notes.

### Experiment registry

Record:

- channel concept;
- audience;
- hypothesis;
- probe format;
- production time and cost;
- packaging;
- distribution;
- viewing depth;
- satisfaction proxies;
- decision.

## 3. Reuse rule

Reuse infrastructure aggressively. Do not reuse a surface template when it makes videos interchangeable.

The library accelerates originality; it must not automate generic mass-produced content.
