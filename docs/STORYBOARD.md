## Sequence

### 1. Cold open

Использовать утверждённый:

`VIDEO-001-proof/remotion/out/cold-open-proof-v3.mp4`

Статус: PASS.

### 2. What “47 seconds” means

1. Крупный счётчик `47 SEC`.
2. Claim `ATTENTION LIMIT` перечёркивается.
3. NOD наблюдается в обычной компьютерной среде.
4. Document → browser reference → message → clock.
5. Выделяется `ONE SCREEN`, а не one idea или one project.
6. Короткая Iceland/volcanoes шутка.
7. Разные временные линии показывают разброс.
8. Вокруг одной задачи появляются возможные выходы.

### 3. External and self-created exits

1. Notification, badge, message и coworker — внешние exits.
2. Уведомления исчезают.
3. NOD самостоятельно тянется к телефону.
4. Сложный абзац вызывает открытие новой вкладки.
5. `Notifications: OFF`, но checking counter продолжает расти.
6. Один notification sound визуализируется как маленький импульс.
7. Ожидаемый «метеор» превращается в небольшой `ping`.
8. Задача окружается множеством возможных направлений.
9. Leaving становится визуально проще, чем continuing.

### 4. Resumption cost

1. NOD собирает графитовую mental model.
2. Message разрывает последовательность.
3. Блоки мысли рассыпаются.
4. Появляются вопросы `What? Where? Next?`.
5. Документ остаётся открытым, но позиция потеряна.
6. Return cue удерживает нить.
7. `25 MIN TO RECOVER` заменяется на `RETURN TO PROJECT`.
8. Document → message → email → calendar → search → document.
9. NOD работает быстрее.
10. Документ завершается, но пространство вокруг NOD сжимается.

### 5. One Door Protocol

Hero reveal:

- NOD;
- одна задача;
- одна хорошо читаемая дверь;
- минимум объектов;
- спокойная cream/graphite композиция.

#### Step 1 — Name the outcome

1. `Study biology` распадается на множество направлений.
2. `Create ten flashcards` получает видимую финишную точку.
3. Дополнительные примеры:
   - `Draft a 150-word opening paragraph`;
   - `Complete and send the form`.

#### Step 2 — Close visible exits

1. Закрываются unrelated tabs.
2. Исчезают badges.
3. Телефон переносится со стола на дальнюю полку.
4. Короткая шутка с монастырём.
5. Дополнительные физические шаги до телефона показывают friction.

#### Step 3 — Park the impulse

1. Над NOD появляются:
   - toothpaste;
   - reply to Alex;
   - Iceland volcanoes.
2. Мысли перемещаются в короткий parking list.
3. Лист начинает превращаться в сложную productivity system.
4. NOD возвращает его к трём простым строкам.

#### Step 4 — Leave a return cue

1. `Continue report` показывается как слабая и размытая инструкция.
2. Она заменяется на `Compare the final two numbers in table three`.
3. Нить mental model закрепляется на стикере.
4. После возвращения NOD сразу продолжает работу.

#### Step 5 — Stop at a breakpoint

1. NOD завершает смысловую секцию.
2. Перед уходом оставляет короткий return cue.
3. На задаче появляется визуальная «ручка».
4. При возвращении NOD не ищет точку входа заново.

### 6. The 25-minute experiment

1. Пять шагов сворачиваются в компактную карточку.
2. Таймер `25:00` с подписью `NOT MAGIC`.
3. NOD готовит рабочее место.
4. Каждый impulse получает одну отметку.
5. Отметки сортируются:
   - external;
   - self-created.
6. Дополнительная сортировка:
   - confusing;
   - uncomfortable;
   - boring.
7. Невидимые exits становятся видимыми оранжевыми контурами.

### 7. Ending

1. `PERFECT FOCUS` разбивается и исчезает.
2. `DOPAMINE RESET` получает штамп `NOT LITERAL`.
3. NOD уходит от задачи и возвращается по сохранённой нити.
4. В кадре остаются:
   - NOD;
   - одна задача;
   - одна дверь.
5. По очереди появляются message, tab и phone.
6. Финальный вопрос: `YOURS?`
7. Оранжевые элементы закрываются.
8. Финал возвращается к спокойной cream/graphite палитре.
