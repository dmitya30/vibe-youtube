# VIBE-YOUTUBE

Исследование и запуск масштабируемого AI-assisted YouTube-медиа.

## Текущий статус

- Этап: исследование и подготовка первого эталонного ролика.
- Основной пилот: English practical self-improvement / visual life skills.
- Первый ролик: attention span, distractions and task switching.
- Канал ещё не зарегистрирован.
- Массовая автоматизация ещё не разрешена.

## Документация

1. [`docs/CONTEXT.md`](docs/CONTEXT.md) — текущий источник истины.
2. [`docs/PLAYBOOK.md`](docs/PLAYBOOK.md) — действующая контентная и производственная система.
3. [`docs/EXPERIMENTS.md`](docs/EXPERIMENTS.md) — гипотезы, ролики и результаты.
4. [`docs/SOURCES.md`](docs/SOURCES.md) — проверенные источники.
5. [`archive/`](archive/) — исторические материалы, не обязательные для ежедневной синхронизации.

## Правило синхронизации

Перед началом нового этапа:

1. Прочитать `CONTEXT.md`.
2. Проверить последний commit.
3. Открыть только относящийся к задаче документ.
4. Перепроверить изменяемые факты через web.
5. Обновить документы и сделать commit.

## Безопасность публичного репозитория

Запрещено коммитить:

- API-ключи и токены;
- cookies и session data;
- платёжные реквизиты;
- документы KYC;
- реальные адреса и договоры;
- приватные данные партнёров;
- неопубликованные пароли и credentials.

Такие данные должны храниться вне репозитория.
