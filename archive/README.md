# Archive

Здесь хранятся исторические материалы, которые больше не являются текущим источником истины.

Главный архивный документ:

`RESEARCH-JOURNAL-through-0.4.md`

После переноса журнала:

- не обновлять его;
- не использовать как текущую стратегию;
- обращаться к нему только для аудита старых решений;
- текущий контекст поддерживать в `docs/CONTEXT.md`;
- историю изменений хранить через Git commits.
