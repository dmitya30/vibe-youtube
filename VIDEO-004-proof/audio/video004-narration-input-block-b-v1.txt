For one task, identify your first escape.

Not the activity that consumes the entire evening. The first turn away: opening email, checking one reference, adjusting the layout, making coffee, or deciding that you need a better plan.

Then ask a narrow question:

What felt difficult in the five seconds before I turned away?

Maybe the task was unclear. Maybe the next step was tedious. Maybe you could not tell whether your work would be good enough. You do not need a clinical label. You only need a useful description of this moment.

Next, replace the project with one visible action.

Not “work on the presentation.” Open slide three and write one deliberately rough heading.

Not “finish the report.” Open the source document and copy the first number you need into the results table.

Not “study chemistry.” Answer the first practice question without looking at the notes.

The action should touch the real task. Color-coding the folder does not count if the folder is where you go to hide.

Making the action concrete does not guarantee that you will continue. It removes one decision from the moment when avoidance is already attractive.

Now attach that action to the cue that normally begins the escape.

Use an if–then plan:

If I open the project and reach for email, then I will write one rough heading before deciding what to do next.

If I feel the urge to find another tutorial, then I will attempt the first problem for two minutes before searching.

Research on implementation intentions suggests that specific if–then plans can help people notice a critical cue and initiate a selected response. They work best as support for a goal you already intend to pursue, not as a way to manufacture a goal you do not want.

So do not turn this into another elaborate system.

Run it once.

Choose one meaningful task. Write down the first escape you expect. Define one visible action that advances the actual work. Connect them in one if–then sentence.

When the cue appears, perform the action before renegotiating with yourself.

You are allowed to stop after that. The experiment is not a promise that one sentence will cure procrastination. It tests whether changing the first response changes the loop.

If the task is impossible because you lack information, time, safety, or support, a smaller first action will not repair the situation. And if persistent difficulty is seriously affecting your life, a general YouTube experiment is not a substitute for qualified help.

But sometimes the task is possible, the goal is still yours, and the escape simply arrives before the work begins.

In that moment, do not ask future-you to become a different person.

Catch the handoff.

Name the first escape. Make the real action visible. Tie it to the cue.

The work that matters most may never feel like the easiest thing to start.

It only needs a first action that can happen before relief steals it again.
