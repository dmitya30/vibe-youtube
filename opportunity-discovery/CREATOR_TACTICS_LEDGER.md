## 1. Why v5 exists

Version four crossed the forty kilobyte threshold that its own rules set for archival, measured at
40407 bytes locally on 2026-08-25. The threshold exists because a ledger that cannot be read in one
pass stops being working memory, and the standing state is then reconstructed from narrative after
every context compression. Versions one to four remain valid evidence and are cited by identifier.
Size is read from the local file rather than from a remote listing, because a compressed transport
size understates the file and cannot drive the threshold.

## 2. Rules

- numbering continues from CTL-0201 and an identifier is never reused, including across all four
  archive boundaries;
- one entry states one mechanic and occupies at most twelve lines;
- every entry names the question it answers by its OQ identifier from OPEN_QUESTIONS.md, or states
  NO_OPEN_QUESTION and explains why it was recorded anyway;
- an entry that overturns or narrows an earlier entry carries a SUPERSEDES line naming the
  identifier, and the same fact is written into the corrections register in OPPORTUNITY_MAP.md in
  the same patch;
- required fields remain those of RESEARCH_PROTOCOL.md section 4, and unknown values are UNKNOWN;
- an archived entry remains valid evidence unless a later entry supersedes it;
- when this file passes roughly forty kilobytes it is archived in turn and v6 opens;
